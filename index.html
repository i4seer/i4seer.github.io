Tick is a compact, Wi-Fi connected sensor that helps you monitor uptime, capture events, and stream data to your backend or the i4Seer Portal with ease.

Meet Tick

Tick is a Wi-Fi connected sensor that delivers the number of ticks since reboot. It can report to the i4Seer Portal or to any JSON-compatible backend, and includes an internal web UI for seamless configuration.

Tick is the first of many sensors from i4Seer. As the foundational module in our growing platform, Tick paves the way for a robust ecosystem of connected, intelligent sensing devices that make edge data capture simpler and smarter.

Wi-Fi 6 Enabled

Supports the latest Wi-Fi 6 (802.11ax) standard for faster, more reliable data delivery.

ESP32-C6 Platform

Powered by the ESP32-C6 chip, delivering efficient processing, BLE 5.0, and advanced networking features.

MicroPython Powered

Built on MicroPython for rapid prototyping and transparent code execution.

Portal Integration

Seamlessly integrates with the i4Seer Portal for real-time monitoring, diagnostics, and analytics.

Configurable via Web UI

Includes a local web interface for Wi-Fi setup, endpoint configuration, and debugging.

USB-C & Expandability

Features USB-C for power and programming, plus GPIO, UART, and I2C for sensor extensions.
