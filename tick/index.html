The Platform

SEER Tick is an integrated monitoring platform for temperature, humidity, and environmental tracking across distributed operations. It combines rugged LoRaWAN sensors, private gateways, a secure cloud console, and email & Teams alerts — one coherent system, one vendor, one support line.


Built for operators who need focused simplicity instead of bloated commercial suites. Battery life measured in years. Private network control. Role-based access. Alerts when thresholds are crossed or devices go silent. Rate-limited ingest that absorbs bad-actor floods. Bearer tokens for Grafana, Power BI, and your own scripts. Audit trail with configurable retention and CSV export. And an open API so your data is always yours.

Microsoft Sign-In

Built on Azure Static Web Apps’ managed identity provider. Works with any Microsoft account — personal, work, or school. Zero AAD registration required. Your org’s existing Microsoft Entra tenants plug in out of the box.

Google Workspace Sign-In

Register a single OAuth app in Google Cloud Console and Workspace users get one-click access. The same allowlist and role model apply to both providers.

Allowlist Enforcement

Only pre-invited emails can sign in. New operators are added by an admin in the Users blade. Revoke access in one click. Every sign-in attempt is logged, successful or not.

Bootstrap Admin

First-run protection: a configured bootstrap email auto-promotes to admin on its first successful sign-in, so a fresh deployment is never locked out of its own Users table.

Fleets & Roles

Devices are organized into fleets. Operators are granted per-fleet roles. A device can live in multiple fleets. A user can be viewer in one fleet and editor in another. Editor wins when roles overlap on a single device.

ADMIN

Full Platform Access

Sees and edits everything. Manages users, fleets, device assignments, and the audit log. Bypasses fleet membership entirely. The role that runs the platform.

EDITOR

Per-Fleet Operator

Sees devices in granted fleets. Sends downlinks: mode changes, sleep modes, confirmed delivery toggles, reboots, counter resets. Cannot modify fleet membership or invite users.

VIEWER

Per-Fleet Observer

Read-only access to devices in granted fleets. Sees telemetry, device health, configuration history. Perfect for stakeholders and monitoring dashboards that shouldn’t touch production.

A non-admin with no fleet grants signs in successfully but sees an empty console until an admin assigns fleets. A device that sits in zero fleets is invisible to non-admins. The model scales from a single operator watching six devices to dozens of operators across hundreds of fleets.

Alerts & Monitoring

Author threshold rules against any metric. Get notified by email or Microsoft Teams when a device crosses the line — or goes silent. Every firing is logged, attributed, and rate-limited so a fleet-wide event can’t flood an operator’s inbox.

Threshold Rules

Fire on temperature, humidity, battery, signal strength, or any metric your devices report. Comparison operators, duration windows, cooldowns. Scope to all devices, a fleet, or a single sensor.

Silence Detection

no_uplink rules catch the most important question: is the device still alive? Fires when a sensor has been quiet longer than the threshold. Never-seen devices fire immediately so you catch provisioning failures on day one.

Email Delivery

Powered by Azure Communication Services. Pay-as-you-go at a fraction of a cent per message. Start with an Azure-managed domain in ten minutes or use your own custom domain with SPF/DKIM for branded sender addresses.

Microsoft Teams

Adaptive Cards posted directly to any channel via incoming webhook. Shows device, metric, condition, value, timestamp, and an Open Dashboard button. Works with classic connectors and the new Workflows automation.

Rate Limiting

Rolling one-hour cap per recipient (default 20/hour, configurable). When the cap hits, suppression counts are tracked and a single digest email summarizes what got dropped. A fleet-wide event cannot flood an inbox.

Event History

Every firing is written to AlertEvents with identity, delivery status, and any errors. Full searchable history for compliance, forensics, and post-incident review.

Quiet Hours

Per-rule HH:MM–HH:MM windows (UTC). Suppress email and Teams delivery during off-hours — the rule still fires and the dashboard still shows the alarm, but nobody gets paged. Crosses-midnight aware. Night-shift support has never been easier.

Test-Fire

One-click synthetic firing through each rule’s configured channels. Validates email, Teams webhooks, routing, and payload formatting without waiting for a real threshold breach. Bypasses rate limits and cooldowns; writes a kind=test row to the event history.

Platform Features

LoRaWAN Long Range

Miles of range, sub-gigahertz spectrum, no Wi-Fi required. Runs on public networks (The Things Network) or your own private LNS. Regional parameters for US915, EU868, AS923, and beyond.

Always-Sleep Firmware

Devices spend 99%+ of their life in deep sleep. Wake, OTAA join, transmit, sleep. Battery budget measured in years, not weeks. Solar-ready for truly unattended deployments.

Eight Interval Modes

Normal (15 min), Test (1 min), Active (5 min), Hourly, Quarter (4 hr), Daily, Silent (24 hr), Config (30 min). Switch any device’s reporting cadence remotely from the console.

Config Self-Reporting

Every boot, every device reports its own firmware version, mode, and settings on the config port. The cloud always knows what’s actually deployed — not what it thinks is deployed.

Unified Downlink Protocol

Single downlink port, compact one-byte command table. Mode change, reboot, counter reset, confirmed-delivery toggle, config report request. /down/replace semantics — only the last command wins.

LED Diagnostics

White / yellow / green / blue / red status LEDs. One glance tells you: unprovisioned, joining, healthy, transmitting, or errored. Field-serviceable without a laptop.

USB Provisioning

Flash firmware and write device credentials over USB with zero manual config-file editing. Devices ship unprovisioned and get their identity burned in at deploy time.

Gateway Health Monitoring

Dedicated health page with Healthy / Stale / Offline summary, lifetime traffic totals, uplink rate, and staleness-sorted per-gateway rows. Swap hardware without touching devices. Read-for-all so operators can triage coverage without admin access.

Full Audit Trail + Export

Every downlink, every mode change, every fleet assignment, every user action, every token issued, every alert firing. Timestamped, identity-attributed, filterable, CSV-exportable. Configurable retention with automatic pruning. Compliance and forensics, solved.

Rate-Limited Ingest

Three-tier token bucket on /api/ingest — per webhook key, per source IP, per device. Absorbs misconfigured devices, replay loops, and leaked-secret floods. Legitimate TTN bursts pass through; abusive traffic gets a 429 with Retry-After. Audit-logged.

API Tokens

Bearer tokens for Grafana, Power BI, CI jobs, and custom dashboards. Three scopes: owner (inherits admin / fleet rights), fleet-scoped read-only, or read-only-global. Expiry dates, sha256-hashed storage, one-click revoke.

Ingest Webhook Auth

TTI webhooks authenticate with a shared-secret header against the ingest endpoint. Webhook identity is separate from operator identity in the audit log. Forge-resistant, replay-resistant, fast.

REST API

First-party endpoints for devices, fleets, users, audit, telemetry, alerts, and tokens. Two auth paths: SWA session cookie (for the browser console) or bearer token (for scripts and integrations). Same OAuth and RBAC model applies to both.

Runs on Free Tier

Azure Static Web App (free). Azure Table Storage (pennies). The Things Network (free community edition) or TTI Cloud (paid tenant). The entire platform fits in a shoebox budget.
