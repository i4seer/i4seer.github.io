Tick / Roadmap

ROADMAP

What ships today. What’s being built now. What’s deferred. Honesty is a positioning advantage.

Shipping Today

If we say it on the main page, it works in production. Firmware 1.1.1 + Backend 1.1.1 are running at tick.i4seer.com right now.

Cellular Bring-Up

SIM7028 over raw AT (no TinyGSM). HTTPS via modem-side TLS. NB-IoT/LTE-M attach with NITZ clock sync. Diagnostic shell.

Three Transport Modes

WiFi only, cellular only, or WiFi with cellular backup. Configurable per device. Per-send failover in backup mode with 8s WiFi timeout and 60s skip-window after 3 fails.

HMAC Auth

HMAC-SHA256 on every POST. Secret derived from MAC + per-fleet salt. Single combined X-Tick-Auth header.

Multi-Tenant Orgs

Org / fleet / role model with platform admins, org owners/editors/viewers, and fleet members. Cascade lives in two functions; every check goes through them.

Per-Device Dashboard

Live transport indicator, signal strength, send/fail counters per pipe, snapshot age, countdown to next refresh. Mobile-responsive.

Per-Org Audit

JSONL audit log per org plus a global audit for pre-org-context events (login attempts, platform-admin actions). Members read their own org’s history.

Public Read-Only View

One operational fleet exposed read-only at /public — field-scrubbed and rate-limited. The demo is the product.

QR Deep-Linking

Each device’s 0.85" screen renders a QR that opens the per-device dashboard page. Scan, fix, walk away.

Building Now

Active priorities. These will land before the first paid customer.

Server-Side Alerting

Fleet-level rule storage. Background evaluator. Email + webhook channels. Dwell-time, cooldown, resolved-notifications. The pager-at-3am feature. Server-side, not device-side — tweak rules without re-flashing.

External Sensor (DS18B20)

Today readings are MCU temperature — a self-monitoring metric. DS18B20 1-Wire probe is the first external sensor: cheap, accurate, waterproof variants. Backend already tolerates unknown payload fields.

Email Password Reset

Today resets are admin-driven. Self-service token-based reset over email is on the path before self-service onboarding.

Off-Droplet Backups

Today: manual rsync. Coming: nightly automated rsync to S3-compatible (Backblaze B2 or DO Spaces). Cheap, decoupled from droplet survival.

Later

On the list, but waiting for a customer to ask. We’re not speculatively building.

Self-Service Claim Tokens

Customer enters a one-time token printed on the device label and the device joins their org. Today: admin clicks Approve.

Charts on Device Detail

Light SVG chart of last ~200 readings, range picker (1h / 24h / 7d / 30d). Most useful once alerting overlays threshold lines on it.

OTA Firmware Updates

USB updates work for any device we can physically reach. Build OTA when there’s a fleet that we can’t.

Stripe Billing

Per-device-per-month, billed to org owner. Won’t exist until someone’s offered to pay for it.

Device-Went-Dark Detection

The other half of alerting: a device that should be reporting and isn’t. Same notification plumbing as threshold alerts; different trigger.

Scale to a Real DB

JSONL is fine to a few thousand devices. Beyond that, TimescaleDB or DuckDB-on-files alongside. Files stay valid through the transition.
