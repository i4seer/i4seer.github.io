Before You Start

Every project has three versions. Pick the one that matches where you are.


Version 1 — stuff from around the house. An LED, a battery, some tape, and maybe a plastic ball from the craft store. No soldering. No wires. Ten minutes, tops.


Version 2 — real electronics. Chips, capacitors, resistors, soldering. More like what the villains actually built. You'll need an adult who knows what a capacitor is. If they don't, find a different adult.


Version 3 — Tick. A real microcontroller running real firmware. Wi-Fi, setup pages, code you can read and modify. What the villain would actually use. Scroll down.


I learned this from a library book and a retired electrician named Earl who lived two streets over. Earl had all his fingers. Learn from an Earl.

Version 3 — Tick

Real microcontrollers. Real firmware. Real code.

Tick is what the villains would actually use. Instead of LEDs and batteries, Version 3 runs on an ESP32 microcontroller with Wi-Fi and firmware you can read and modify. Each device has its own setup page — themed to the book — served right from the hardware.


Hold the button, connect to its hotspot, and configure from a web page. No internet required. No server. No app. Just the device and your phone’s browser.


Firmware comes pre-loaded. To update, just plug in USB — the device shows up as a drive. Drag and drop new files. All code is CircuitPython — Python you can read.
