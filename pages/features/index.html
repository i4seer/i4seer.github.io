Sensing Capabilities

What Tick can detect and monitor right out of the box

🔢

Incremental Counting

Persistent counters stored in Notecard flash survive both MCU resets and power loss. Track events, cycles, pulses, or any activity. Counts sync to cloud automatically.

🔋

Battery & Power Monitoring

Track battery voltage, USB power status, and power source changes. Low battery alerts notify you before the device goes offline.

📶

Connection Monitoring

Track signal strength, connection status, and link quality across cellular, WiFi, or LoRa. Historical data helps identify coverage issues and optimize placement.

📍

Movement & Tamper Detection

Built-in Notecard accelerometer detects motion events without external sensors. Know when the device is moved, tilted, dropped, or tampered with. Protect assets that shouldn't be relocated.

🛰

GPS Location Tracking

Integrated GPS on Cell and Cell+WiFi variants. Configurable tracking intervals with cell-tower triangulation fallback for indoor locations.

🔔

Threshold Alerts

Unified alert system with deduplication. Alerts for low battery, weak signal, sensor failures, and custom thresholds.

🌡

Climate Sensing

BMP390 environmental sensor measures barometric pressure (300–1250 hPa) and temperature (-40 to +85°C). Track weather patterns, altitude changes, and ambient conditions via I2C Qwiic.

🌬

Pressure Sensing

SM8436 ultra-low differential pressure sensor (-20 to 500 Pa). Detect subtle airflow changes for HVAC, clean rooms, and ventilation with per-reading min/max/stdev statistics.

🔧

Custom Sensing

Need air quality, CO2, humidity, vibration, or light? The I2C Qwiic port supports hundreds of sensor types. We design and integrate custom add-ons for your application.

Coming Soon

🚶

Human Detection

PIR and thermal sensing for occupancy counting, room utilization, and people flow analytics. No cameras, no privacy concerns.

🔊

Sound Detection

Acoustic monitoring for equipment noise levels, alarm detection, and ambient sound analysis. Threshold-based alerts without recording audio.

💡

And More

Air quality, CO2, humidity, vibration, and light sensing add-ons in development. Contact us to request a sensor or discuss your needs.

Reliability & Long-Term Operation

Designed for unattended 24/7 deployments

🛡️

Hardware Watchdog

STM32 IWDG watchdog with configurable timeout up to 32 seconds. Automatically restarts the device if firmware hangs. Crash recovery without human intervention.

🔄

Auto-Reboot Scheduling

Configure automatic reboots after N hours of operation. Prevent memory leaks and ensure fresh state. Data syncs before reboot.

🕐

Notecard Time Sync

Automatic time synchronization via cellular network. Accurate timestamps for all readings without NTP configuration.

📊

Boot Mode Tracking

Boot, reboot, and tick counters stored in Notecard flash (.dbx notefiles). Know exactly why your device rebooted and debug issues with complete reboot history.

💾

Persistent Settings

Notecard flash storage for counters and configuration. Critical settings survive power loss and unexpected reboots. No data lost.

🚨

Alert System

Unified alert notefile for anomalies. Rate-limited, deduplicated alerts for low battery, connectivity issues, sensor failures, and watchdog resets.

Efficient Data Transfer

Smart protocols minimize bandwidth while maximizing insights

📉

Statistical Aggregation

Pressure sensor reports min, max, standard deviation, and sample count per reading. Environmental sensor reports calibrated pressure and temperature. Reduces sync payloads while preserving data quality.

⚡

Compact Templates

Notecard note.template system compresses JSON payloads. Define field types once, send minimal data on each reading.

💓

Heartbeat Tracking

Tick counter serves as heartbeat. Boot and reboot counters track device lifecycle. Detect unplanned restarts with simple math.

⏱️

Configurable Intervals

Independent per-sensor intervals via profile system. High-frequency for critical values, low-frequency for slow trends. Balance accuracy vs bandwidth.

🔀

Profile-Based Config

Four built-in profiles (DEV, PROD_ACTIVE, PROD, LOW_POWER) control all timing. Switch remotely via environment variable.

📶

Connection Resilience

Notecard store-and-forward architecture queues notes in flash. Data syncs automatically when connectivity returns, regardless of radio type.

Developer Tools

Complete observability and control for builders

💻

Notecard JSON API

Simple JSON request/response protocol over I2C. card.version, note.add, hub.set, env.get — straightforward API for all device operations.

📋

Profile-Based Config

Four compiled profiles with 15+ settings each. Override remotely via Notehub environment variables.

📝

Serial Debug Output

Detailed serial logging at 115200 baud for development. Sensor status, I2C bus health, profile changes, and alert events.

🎯

I2C Sensor Add-Ons

Qwiic I2C bus with auto-detect. Add the Environmental Sensor (BMP390) or Pressure Sensor (SM8436) add-ons, or integrate any I2C sensor.

🔄

OTA Updates

Notecard Outboard DFU reflashes the STM32 over UART via any connectivity variant. Even bricked firmware can be replaced remotely.

🧩

Compile-Time Registry

Adding a new sensor is 3 steps: add interval to config, create sensor module, add one line to registry table.
