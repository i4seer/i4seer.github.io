Built-in Sensing Capabilities

Ready to detect and count out of the box—no external sensors required

🔢

Incremental Counting

Persistent counters that survive power loss. Track events, cycles, pulses, or any activity that needs counting. Know exactly when and how often things happen.

⚡

Power Loss Detection

Detect power outages and track uptime. Know when equipment lost power, how long it was off, and when it came back online.

📶

Connection Monitoring

Track connectivity status, signal strength, and connection drops across WiFi, cellular, or LoRa links. Get alerts when network issues affect operations.

📍

Movement Detection

With an optional accelerometer, detect when the device is moved, tilted, or tampered with. Monitor equipment that shouldn't be relocated.

🚶

Presence Sensing

Add a PIR sensor to detect when people or animals pass by. Count foot traffic, monitor occupancy, or trigger alerts on motion.

🌡️

Environmental Sensing

Connect temperature, humidity, air quality, or any I2C sensor. Expand capabilities as your monitoring needs grow.

What's Inside

Every component chosen for reliability and performance

🧠

RP2350 Processor

Raspberry Pi's latest dual-core ARM Cortex-M33 running at 150 MHz with 520KB SRAM. Powerful enough for edge computing, efficient enough for 24/7 operation.

📶

Flexible Connectivity

WiFi 6 (802.11ax) standard. Optional LTE cellular or LoRa modules for remote deployments where WiFi isn't available.

🔋

USB-C Power

Standard USB-C connector for easy power. Works with any 5V USB power source—wall adapters, battery packs, or powered USB hubs.

🔧

I2C Expansion

4-pin JST connector provides 3.3V I2C bus access. Connect temperature sensors, air quality monitors, accelerometers, and hundreds of other I2C devices.

🏭

Aluminum Enclosure

Black anodized aluminum case with mounting holes. Provides RF shielding, heat dissipation, and protection for industrial environments.

💡

Status LED

Blue LED indicates device status at a glance. Solid for connected, blinking for activity, off for standby mode.

Integration & Automation

Connect locally or remotely—Tick works with your existing systems

🌐

Local HTTP API

RESTful endpoints accessible on your local network. Query sensor data, send commands, and configure settings without cloud dependency.

☁️

Cloud Twin API

Azure-based REST API for remote access. Push readings, receive commands, and manage devices from anywhere with internet access.

🔗

Webhook Support

Trigger external systems on events. Send alerts to Slack, update databases, or integrate with automation platforms.

📊

JSON Data Format

All data exchanged in standard JSON. Easy parsing for any programming language or integration platform.

🏠

Home Assistant

Native integration with Home Assistant for smart home automation. Expose sensors and control devices through your HA dashboard.
