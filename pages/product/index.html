Connectivity Options

Every Tick uses a Blues Notecard radio module. Swap the Notecard to change connectivity without changing firmware.

📡

Tick Cell

LTE-M / NB-IoT cellular with integrated GPS. Deploy anywhere with cell coverage, no local infrastructure required.

  • ✓ Cellular LTE-M / NB-IoT
  • ✓ Integrated GPS + cell-tower triangulation
  • ✓ Store-and-forward in spotty coverage
  • ✓ Requires cellular data plan
📶

Tick WiFi & Cell+WiFi

WiFi for facilities with existing networks. Choose WiFi-only for lower cost, or Cell+WiFi for cellular fallback when WiFi drops.

  • ✓ WiFi 802.11 b/g/n
  • ✓ Cell+WiFi adds cellular fallback + GPS
  • ✓ Works on existing WiFi infrastructure
  • ✓ Higher throughput for data-heavy apps
🔗

Tick LoRa

Long-range, low-power radio for wide-area sensor networks. Connect dozens of Ticks to a single LoRa gateway.

  • ✓ LoRa long-range radio
  • ✓ Ultra-low power consumption
  • ✓ No per-device cellular cost
  • ✓ Requires LoRa gateway

What's Inside

Every component chosen for reliability and performance

🧠

STM32L4 Processor

ARM Cortex-M4 at 80 MHz with 256KB Flash and 64KB SRAM. Ultra-low-power with 4uA idle current. Efficient enough for years of battery operation.

📶

Swappable Notecard Radio

Blues Notecard module provides connectivity. Available in Cellular, WiFi, Cell+WiFi, and LoRa variants. Swap the radio without changing firmware.

🔋

USB-C Power

Standard USB-C connector for easy power. Works with any 5V USB power source—wall adapters, battery packs, or powered USB hubs. LiPo battery connector with charging circuit for portable deployments.

🔧

I2C Expansion

Qwiic/StemmaQT connector provides 3.3V I2C bus access. Connect temperature sensors, air quality monitors, accelerometers, and hundreds of other I2C devices.

🏭

Notecarrier CX Board

All-in-one carrier board with MCU, Notecard socket, battery charging, and expansion headers. 76mm x 38mm form factor.

📍

Built-in GPS

Integrated GPS with cell-tower triangulation fallback. Track assets outdoors and indoors with automatic location updates.

Device Management

Remote configuration, OTA updates, and store-and-forward reliability

🌐

Store & Forward

Data queues in Notecard flash when offline. Syncs automatically when connectivity returns. No data lost during outages.

⚙️

Remote Configuration

Switch operating profiles from the cloud. Adjust sync intervals, GPS behavior, and sensor rates without touching the device.

🔄

OTA Updates

Push firmware updates over the air. The Notecard can reflash the MCU remotely via any connectivity variant, even recovering from bricked firmware.
