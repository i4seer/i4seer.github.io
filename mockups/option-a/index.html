Three ways to deploy.

Same device. Same firmware. Pick where the data lands.

Mode 1

Bring your own backend

Point Tick at any HTTPS endpoint. JSON payload, HMAC-SHA256 header, predictable schema. Tick becomes a turn-key device fleet feeding your existing pipeline.
Mode 2

Self-host our backend

Run the FastAPI portal on your own server. $4/mo droplet. Multi-tenant orgs, JSONL on disk, rsync backups. Your data, your hardware, our code.
Mode 3 · Default

i4Seer-hosted portal

Sign up, plug in, see live telemetry. We run the droplet, the TLS, the backups, the upgrades. Easiest on-ramp for new devices.
// transports

Pick the pipe per site.

WiFi for connected sites. Cellular for places without IT. Both for places where downtime hurts.

Transport 1

WiFi only

For offices, kitchens, warehouses with reliable WiFi. No cellular cost, no SIM. Sub-1s round trip.

Transport 2

Cellular only

For rentals, jobsites, mobile units, remote outbuildings. NB-IoT/LTE-M with global Hologram SIM. 95%+ US/EU coverage.

Transport 3

WiFi + cellular backup

WiFi-primary to save cost; falls through to cell on any failure — per send, not per session. An ISP outage can’t take you offline.
