// 01 · Sense often, report smart

The accumulator pattern.

Sample every 30 seconds, send every 30 minutes. Each report carries lo / hi / avg / last for the window. A 30-second freezer spike still shows up as hi. The accumulator is NVS-persistent — outages don’t cost you data.

// 02 · No reading lost

Sensing decoupled from transport.

WiFi down, cell down, both down — the device keeps reading and folding values into the persistent window. When transport recovers, the next send carries the full window with first/last timestamps.
