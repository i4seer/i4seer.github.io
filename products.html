Tick

Tick is a Wi-Fi connected sensor that delivers the number of ticks since reboot. It reports to the i4Seer Portal or any JSON-compatible backend, and features an internal web UI for easy configuration.

  • Wi-Fi 6 Enabled
  • ESP32-C6 Platform
  • MicroPython Powered
  • Portal Integration
  • Configurable via Web UI
  • USB-C & Expandable
